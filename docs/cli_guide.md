# CLI User Guide - flutter_marketing_kit

The `flutter_marketing_cli` provides 13 single commands to manage your marketing asset lifecycle.

## Commands Reference

| Command | Usage | Description |
| :--- | :--- | :--- |
| `init` | `dart run flutter_marketing_kit init` | Create `playstore_assets.yaml` configuration |
| `generate` | `dart run flutter_marketing_kit generate` | Run full asset generation pipeline |
| `screenshots` | `dart run flutter_marketing_kit screenshots` | Capture raw screen viewports |
| `frames` | `dart run flutter_marketing_kit frames` | Render SVG device mockups & shadows |
| `feature-graphic` | `dart run flutter_marketing_kit feature-graphic` | Build 1024x500 feature graphic |
| `templates` | `dart run flutter_marketing_kit templates` | List available visual templates |
| `devices` | `dart run flutter_marketing_kit devices` | View supported hardware specs |
| `doctor` | `dart run flutter_marketing_kit doctor` | Run environment diagnostics |
| `preview` | `dart run flutter_marketing_kit preview` | Preview mockups |
| `resize` | `dart run flutter_marketing_kit resize` | Batch resize images |
| `clean` | `dart run flutter_marketing_kit clean` | Wipe generated marketing directory |
| `version` | `dart run flutter_marketing_kit version` | Display tool version |
| `help` | `dart run flutter_marketing_kit help` | Display usage instructions |
