# Migration & Integration Guide

`flutter_marketing_kit` is designed for zero-config onboarding into any existing Flutter codebase.

## Quick Setup Steps

1. Add `flutter_marketing_kit` to `pubspec.yaml`.
2. Initialize configuration:
   ```bash
   dart run flutter_marketing_kit init
   ```
3. Update route names in `playstore_assets.yaml`.
4. Generate assets:
   ```bash
   dart run flutter_marketing_kit generate
   ```
