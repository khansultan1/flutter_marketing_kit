# Changelog

All notable changes to `flutter_marketing_kit` will be documented in this file.

## [1.0.0] - 2026-08-03

### Added
- Initial release of `flutter_marketing_kit`.
- Modular Melos monorepo packages.
- CLI runner supporting `init`, `generate`, `screenshots`, `frames`, `templates`, `devices`, `feature-graphic`, `doctor`, `preview`, `resize`, `clean`, `version`, and `help`.
- YAML configuration engine parsing `playstore_assets.yaml`.
- Shared domain models and specs for devices, stores, and color themes.
